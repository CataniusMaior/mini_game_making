# DRIFT ARK — 世代船グリッド航行記

グリッドにモジュールを配置して世代船（何世代もかけて旅する移民船）を運営し、2,400光年先の惑星ヴェルダを目指すターン制シミュレーションです。ブラウザだけで動き、依存ライブラリやビルドは不要です。

グリッドに施設を並べて宇宙船を運営する、かつてのブラウザゲーム（Nussy Game『Lonely Colony』など）に着想を得たオリジナル作品です。名前・設定・モジュールの構成・数値・見た目はすべて独自のものです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages などの静的ホスティングにそのまま置くこともできます。進行状況はブラウザの localStorage に自動保存され、「続きから」で再開できます。

- URL に `?seed=123` を付けると、航路と乱数を固定して始められます。

### 目的

- 目的地ヴェルダまで 2,400 光年。人口が 0 になるか、300 ターンを過ぎると失敗です。
- 到着時の人口・士気・かかったターン数でスコアとランク（S〜C）が決まります。

### 1ターンの流れ

1. 作業回数（初期 2、工房 1 つごとに +1、最大 5）の範囲で、建造・修理・撤去・外殻拡張を行う。研究と、モジュールの稼働／停止の切り替えは作業回数を使いません。
2. 航行モード（停泊／巡航／全速）を選ぶ。
3. 「ターン終了」（Enter キー）で、生産・消費・航行・劣化・イベントが処理されます。

### 配置のルール

| ルール | 内容 |
| --- | --- |
| 酸素 | 居住区は生命維持装置（またはバイオドーム）の周囲 1 マス（3×3）の中でなければ住めない |
| 船尾 | 推進器は左隣が船外のマスにしか置けない（船は右へ進む） |
| 外縁 | 集光パネルとドローン格納庫は、上下左右のどこかが船外のマスにしか置けない |
| 隣接 | 水耕農場は生命維持装置の隣で +2、推進器は炉の隣で推力 +20%、研究ラボは並べると +1 |
| 排熱 | 核分裂炉の隣の居住区は士気が下がる |
| 外殻拡張 | 船体の外側に区画を増やせる。推進器の噴射口や外縁専用モジュールを塞ぐ拡張は不可 |

### 資源と船の仕組み

- **電力**：優先度の高い区画（生命維持 → 居住区 → 農場 → 推進器 …）から順に配られ、足りない区画は止まります。艦橋の補助電源が常に 6 発電します。
- **人手**：人口がそのまま人手です。不足すると優先度の低い区画から効率が落ちます。
- **燃料**：炉に優先して回り、残りが推進器へ。燃料精製所で資材から作れるほか、星雲ではガスを集められます。
- **資材**：ドローン格納庫で採取。小惑星帯や恒星系で増え、停泊中は 2 倍。
- **士気**：条件から決まる「目標値」へ毎ターン少しずつ近づきます。低いと効率低下や暴動、高いと効率と人口増加が上がります。
- **劣化**：稼働するほど耐久が減り、尽きるか 30% 未満で故障することがあります。資材 15 と作業 1 回で修理できます。
- **速度** = 3 + 45 × 推力 ÷ 質量。モジュールや外殻を増やすほど船は重くなります。
- **宙域**：通常・小惑星帯・星雲・恒星系・漂流船の墓場・暗黒宙域があり、光の強さ、採取量、イベントが変わります。長距離スキャナを研究すると、先の宙域まで観測できます。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     スタイル
js/data.js        モジュール・研究・宙域・数値の定義（バランス調整はここ）
js/game.js        ゲームロジック（DOM 非依存。Node からも読み込める）
js/ui.js          描画と操作
tests/            Node の組み込みテストランナー用テスト
tools/bot.js      バランス確認用の自動プレイボット
```

## 開発

Node.js 18 以上で、テストとバランス確認を実行できます（ゲーム自体には不要です）。

```bash
npm test
```

```bash
npm run balance
```

`npm run balance` は簡易ボットで 100 回航海し、到着率・平均ターン・ランク分布を表示します。現在の調整では、簡易ボットの到着率はおよそ 9 割（平均 119 ターン）で、何もしない場合は到着できません。
